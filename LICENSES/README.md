# Licensing map

Nasaru intentionally uses a per-path licensing model.

| Path | License |
|---|---|
| `crates/**`, `training/**`, userspace code | GPL-3.0-or-later |
| `kernel/**`, eBPF/KO source | GPL-2.0-only |
| `docs/**`, Riksu specification | CC-BY-SA-4.0 |

Full license texts are stored in this directory. New source files must carry an SPDX identifier matching their subtree.
