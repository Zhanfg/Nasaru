# Nasaru optional kernel module

The KO is a fallback enforcement component, not the policy brain.

It may expose only compact primitives such as UID policy state, capability bitmap, and bounded audit transport. AI inference, user databases, package classification, and training do not belong in kernel space.

Release CI will eventually build a KMI matrix and attach manifest, vermagic, required symbol set, toolchain version and SHA-256 hashes.
